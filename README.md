# Robolympics

Sitio web oficial de Robolympics — Tec de Monterrey Campus León.

## Estructura inicial

- `index.html`: portada del sitio.
- `pages/convocatoria.html`: convocatoria vigente.
- `pages/categorias.html`: categorías y retos.
- `pages/registro.html`: proceso de inscripción.
- `pages/programa.html`: agenda y fechas clave.
- `pages/ediciones.html`: archivo histórico.
- `pages/contacto.html`: contacto y preguntas frecuentes.
- `assets/css/styles.css`: sistema visual y estilos responsive.
- `assets/js/main.js`: navegación móvil y comportamiento básico.

## Rama de trabajo

La primera versión del sitio se desarrolla en `setup/estructura-inicial` y se revisa mediante Pull Request antes de integrarse a `main`.

## Vista temporal con GitHub Pages

La rama incluye `.nojekyll` y está preparada para publicarse directamente desde la raíz mediante GitHub Pages.

Configuración requerida una sola vez en GitHub:

1. `Settings` → `Pages`.
2. En `Build and deployment`, seleccionar `Deploy from a branch`.
3. Seleccionar la rama `setup/estructura-inicial`.
4. Seleccionar la carpeta `/(root)`.
5. Pulsar `Save`.

La URL esperada del sitio es:

`https://profcduquetec.github.io/robolympics/`

Una vez configurado, los cambios enviados a la rama de trabajo se reflejarán en la vista temporal de GitHub Pages.
