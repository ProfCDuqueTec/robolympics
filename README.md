# Robolympics

Sitio web oficial de **Robolympics**, competencia de robótica del Tec de Monterrey Campus León.

## Estado

En construcción. La rama `setup/estructura-inicial` contiene la primera arquitectura navegable del sitio.

## Estructura inicial

```text
robolympics/
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   └── js/
│       └── main.js
└── pages/
    ├── convocatoria.html
    ├── categorias.html
    ├── registro.html
    ├── programa.html
    ├── ediciones.html
    └── contacto.html
```

## Secciones

- Inicio: propuesta de valor y accesos rápidos.
- Convocatoria: requisitos, fechas, documentos y reglamentos.
- Categorías: retos, especificaciones y criterios de evaluación.
- Registro: proceso de inscripción y acceso al formulario oficial.
- Programa: agenda y horarios del evento.
- Ediciones: archivo histórico, resultados y memoria multimedia.
- Contacto: canales oficiales del comité organizador.

## Principios de implementación

- Sitio estático, ligero y compatible con GitHub Pages.
- Diseño responsive para computadora y móvil.
- Navegación sencilla y centrada en las necesidades de participantes.
- Contenido histórico separado de la convocatoria vigente.
- Datos de futuras ediciones marcados como pendientes hasta contar con información oficial.
